04). System Overview

HostelMS is a full-stack mobile application built using React Native, Node.js, and MongoDB. It provides a comprehensive solution for managing room allocations, maintenance requests, visitors, and financials in a hostel environment.

Features implemented:

Secure JWT-based Authentication
Full CRUD for Rooms (with Image Uploads)
Student Room Booking & Approval Workflow
Maintenance Request Tracking
Visitor Digital Registration
Fee Payment History & Proof Uploads
Real-time Analytics Dashboard for Admins
